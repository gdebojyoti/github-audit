How to read this
  • Status: public or private visibility on GitHub. Only public repos were audited so far.
  • Last commit: committer date of the newest commit on the default branch (not GitHub's "updated" date).
  • Action is a suggestion. Archiving is reversible and read-only, so it's usually safer than deleting.
  • "Responds" means the URL returned HTTP 200 on the audit date. It doesn't confirm that URL serves this app.
